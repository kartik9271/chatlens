# 🔍 ChatLens

**ChatLens** is a lightweight, web-based tool designed to help you easily filter, search, and navigate through WhatsApp group chat exports. Whether you are looking for specific messages, filtering by sender, or cleaning up clutter, ChatLens makes exploring chat histories fast and intuitive.

🌐 **Live Demo:** [https://kartik9721.github.io/chatlens/](https://kartik9721.github.io/chatlens/)

---

## ✨ Features

* **Advanced Filtering:** Quickly filter messages by keywords, dates, or specific participants.
* **Client-Side Privacy:** Your chat data stays secure in your browser—nothing is uploaded or stored on external servers.
* **Clean & Responsive UI:** Designed for a smooth, distraction-free user experience on both desktop and mobile devices.
* **Fast Search:** Instant keyword lookup to find exact moments in long conversation logs.

---

## 🚀 Getting Started

1. Export your WhatsApp chat (without media) as a `.txt` file from your mobile app.
2. Visit the [Live Demo](https://kartik9721.github.io/chatlens/).
3. Upload or paste your chat export to start filtering instantly!
